# Анализ данных о сотрудниках и прогнозирование текучести персоналаО проекте

Проект посвящён исследованию данных о сотрудниках компании с использованием инструментов Python. В рамках работы проведён первичный статистический анализ данных, изучены распределения показателей и взаимосвязи между переменными, а также проверена статистическая гипотеза о зависимости заработной платы от продолжительности рабочего времени.

Отдельная часть проекта посвящена построению простой модели машинного обучения для прогнозирования ухода сотрудников из компании и оценке качества полученной модели.

# Цели проекта:
- Провести исследовательский анализ данных о сотрудниках.
- Рассчитать основные статистические показатели и изучить распределение признаков.
- Исследовать взаимосвязи между переменными и определить силу корреляции.
- Проверить статистическую гипотезу о наличии значимой зависимости между уровнем заработной платы и продолжительностью рабочего времени.
- Построить модель для прогнозирования ухода сотрудника из компании.
- Оценить качество работы модели с помощью подходящих метрик.

# В ходе проекта:
- Выполнена загрузка и первичное изучение датасета.
- Проведена проверка структуры и характеристик данных.
- Рассчитаны меры центральной тенденции: среднее значение, медиана и мода.
- Рассчитаны показатели разброса и вариативности данных.
- Исследованы распределения числовых признаков.
- Построены визуализации для анализа данных и взаимосвязей между переменными.
- Проведён корреляционный анализ.
- Сформулирована и проверена статистическая гипотеза о зависимости заработной платы от продолжительности рабочего времени.
- Подготовлены данные для машинного обучения.
- Построена модель классификации для прогнозирования увольнения сотрудников.
- Проведена оценка качества модели и интерпретация полученных результатов.

# Инструменты:
- Python
- Pandas — загрузка, обработка и анализ данных
- NumPy — математические операции
- Matplotlib / Seaborn — визуализация данных
- SciPy — статистический анализ и проверка гипотез
- Scikit-learn — построение и оценка модели машинного обучения
# Результат
В результате проекта проведён комплексный анализ данных о сотрудниках: от первичного исследования и описательной статистики до проверки статистической гипотезы и построения первой модели машинного обучения.
Проект демонстрирует навыки работы с данными на Python, проведения исследовательского анализа, визуализации, статистического тестирования и решения задач бинарной классификации.
