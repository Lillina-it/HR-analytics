# HR-analytics
Анализ данных о сотрудниках с помощью Python. Проведены статистический и корреляционный анализы, изучены распределения показателей и проверена гипотеза о зависимости зарплаты от рабочего времени. Построена и оценена модель машинного обучения для прогнозирования увольнения сотрудников.
